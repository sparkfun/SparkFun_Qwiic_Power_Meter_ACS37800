## SparkFun ACS37800 Power Monitor Arduino Library

The SparkFun ACS37800 Power Monitor Arduino Library is a simple library to configure and use the ACS37800 over I<sup>2</sup>C. You can install the library with the Arduino [Library manager](https://docs.arduino.cc/software/ide-v2/tutorials/ide-v2-installing-a-library/) tool by searching for "SparkFun ACS37800". If you'd prefer a manual install, you can download a ZIP of the library [here](https://github.com/sparkfun/SparkFun_ACS37800_Power_Monitor_Arduino_Library/archive/refs/heads/main.zip).
